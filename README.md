
# 📊 Excel Sales Dashboard

## 📌 Project Overview

This project is an interactive Sales Dashboard created using Microsoft Excel to analyze sales performance, profit, targets, and business trends.

The dashboard transforms raw sales data into meaningful insights using Pivot Tables, charts, KPIs, and Excel formulas.

This project demonstrates my practical skills in Excel Data Analysis, Data Visualization, and Dashboard Development.

---

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Track sales against business targets.
- Identify sales trends by month and day.
- Compare sales performance across departments.
- Identify the top 5 customers by sales.
- Create a user-friendly and visually appealing dashboard.
